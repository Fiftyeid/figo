# Production notes

## What the source plan got wrong
- It claims **37 vehicles**; the shot list actually names **52**. This build covers all 52.
- It lists "2S34 Koalitsiya"; 2S34 is **Khosta** (Gvozdika-based gun-mortar).
  Koalitsiya-SV is the 2S35, a different vehicle.
- It plans loss-count graphics "validated against Oryx". Those numbers move weekly and
  cannot be sourced reliably from here, so the film carries no per-vehicle loss figures
  and states on screen that recorded losses are visually confirmed only.

## What we kept from the plan
- Countdown-educational pacing, technical callouts, service-entry years.
- One continuous narration voice, steady documentary delivery.
- Static renders with technical overlays (no live footage).

## What we changed
- Visual system: the plan's "desaturated greys + dramatic lighting" was replaced by the
  requested clean white technical display unit: red / white / ink type, no shadows.
- No camera moves: the stills are genuinely still; rhythm comes from cuts timed to pauses
  in the voice track.
- Score is synthesised (drone + pulse) rather than library music, so it is licence-clean.

## Timing
Voice track 13:39, film 13:42. Cuts fall on the pauses detected in the TTS track, so a
vehicle card changes while the previous sentence is still ringing out.

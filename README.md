# مِداد · Midad — استوديو كتب التلوين لـ Amazon KDP

تطبيق محلي (يعمل على جهازك فقط) لصناعة **كتب تلوين احترافية** بالذكاء الاصطناعي،
وتصديرها في ملفات PDF **مطابقة لمعايير Amazon KDP** للكتب الورقية: الداخل بدقة
300 DPI، والغلاف الكامل مع الكعب والنزف ومنطقة الباركود.

> لا سحابة، لا حساب، لا اشتراك. مشاريعك ومفاتيحك تبقى داخل مجلد `data/` على جهازك.

## لماذا هذا التطبيق

صناعة كتاب تلوين للبيع على أمازون ليست مجرد «توليد صور»: يجب أن يكون الملف
قابلًا للطباعة فعلًا. هذا التطبيق يتولّى الأجزاء الصعبة تلقائيًا:

| المشكلة | ما يفعله مِداد |
| --- | --- |
| صور الذكاء الاصطناعي ملوّنة أو برمادية | يحوّلها إلى **خطوط سوداء نقية على أبيض** (1-bit) صالحة للتلوين |
| دقة الصور غير كافية | يعيد بناء كل صفحة بدقة **300 DPI** على مقاس صندوق المحتوى بالضبط |
| الهوامش والـ gutter | يحسبها من **جدول KDP الرسمي** حسب عدد الصفحات ولا يسمح بأقل من الحد |
| عرض الكعب (Spine) | يحسبه بمعادلة `عدد الصفحات × سمك الورق` ويبني الغلاف كاملًا |
| منطقة الباركود | يحجز `2" × 1.2"` فارغة أسفل يمين الغلاف الخلفي |
| نص على الكعب | يمنعه تلقائيًا إن كان الكتاب أقل من 80 صفحة |
| عدد الصفحات | يضبطه زوجيًا وبحد أدنى 24 صفحة، ويضيف صفحات فاصلة عند الحاجة |
| نسيان متطلبات النشر | تقرير فحص بـ 18+ بندًا + قائمة تحقق قبل الرفع |

## التشغيل السريع

### المتطلبات

- Python **3.10+** (يُنزَّل من [python.org](https://www.python.org/downloads/) — على Windows
  فعّل خيار **Add Python to PATH**).
- لا تحتاج أي مفاتيح API للبدء: المحرّك المحلي يرسم صفحات كاملة بدون إنترنت.

### Windows

1. فكّ ضغط المجلد.
2. انقر مرتين على **`run.bat`**.
3. أول مرة فقط: يُنشئ بيئة افتراضية ويثبّت الحزم (دقيقة أو دقيقتان).
4. تُفتح نافذة التطبيق تلقائيًا على `http://127.0.0.1:8000`.

### macOS

انقر مرتين على **`run.command`**.
(إن منعك النظام: `System Settings → Privacy & Security → Open Anyway`، أو نفّذ
`chmod +x run.command` في الطرفية.)

### Linux

```bash
./run.sh
```

### حزمة جاهزة للتحميل (بدون Git)

تُبنى الحزم بـ `python tools/make_release.py` وتُحفظ في مجلد `releases/`:

| الملف | الحجم | لمن؟ |
| --- | --- | --- |
| `midad-kdp-studio-v1.0.zip` | 1.2 MB | كل الأنظمة — التثبيت يحتاج إنترنت مرة واحدة |
| `midad-kdp-studio-v1.0-win64-offline.zip` | 30 MB | ويندوز + Python 3.11 — تثبيت **بدون إنترنت** (يحتوي مجلد `wheels/`) |

يمكنك تنزيلها أيضًا من داخل التطبيق عبر زر **«⬇ تحميل البرنامج»** في الشريط العلوي
(يختار النسخة المناسبة لنظامك تلقائيًا).

لإعادة بناء الحزم:

```bash
python tools/make_release.py                                  # حزمة عالمية
pip download -d wheels --only-binary=:all: --platform win_amd64 \
    --python-version 3.11 --implementation cp -r requirements.txt
python tools/make_release.py --wheels wheels --suffix win64-offline
```

محتوى الحزمة: الكود + ملفات التشغيل (`run.bat` / `run.command` / `run.sh` / `midad.py`)
+ `requirements.txt` + الخطوط العربية + `QUICK-START.txt` + `README.md` + `LICENSE.md`.

### يدويًا (أي نظام)

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python midad.py
```

خيارات إضافية:

```bash
python midad.py --port 9000      # منفذ مختلف
python midad.py --no-browser     # بدون فتح المتصفح
python midad.py --host 0.0.0.0   # للوصول من جهاز آخر على الشبكة
```

## استخدام التطبيق خطوة بخطوة

1. **بيانات النشر** (الشريط الجانبي): العنوان، العنوان الفرعي، المؤلف، الوصف،
   7 كلمات مفتاحية، السعر وتكلفة الطباعة (لعرض العمولة التقديرية).
2. **المقاس والطباعة**: اختر مقاس القطع (الافتراضي `8.5" × 11"` الأشهر لكتب التلوين)،
   ونوع الورق (يحدد سمك الكعب)، وخيار «صفحة فارغة بعد كل رسمة» (يمنع تسرّب الألوان)،
   والنزف إن كانت رسوماتك تلمس الحواف.
3. **ولّد الصفحات**: اختر موضوعًا (حيوانات، ديناصورات، ماندالا، زهور…)، ومحرّك التوليد،
   وعدد الصفحات، ثم اضغط **توليد**. تظهر الصفحات تدريجيًا مع شريط تقدّم.
4. **اضبط أي صفحة**: اضغط على الصورة لفتح المحرّر — عدّل سماكة الخطوط أو عتبة
   الأبيض/الأسود، أو أعد التوليد، أو عيّنها كغلاف.
   يمكنك أيضًا **استيراد صورك** الجاهزة (PNG/JPG) من زر «استيراد صور».
5. **تصدير ملفات KDP**: يبني الداخل والغلاف ونسخة الإثبات، ويفحص المطابقة،
   ويجمع كل شيء في ملف ZIP واحد.
6. **فحص KDP**: تقرير مفصّل بكل بند (سليم / تنبيه / مشكلة) مع طريقة الإصلاح.

> نصيحة: ابدأ بـ 18–24 رسمة. مع الصفحات الفاصلة والتمهيد تصل إلى 40+ صفحة،
> وهو ما يبدو أفضل في الطباعة ويحسّن هامش الربح.

## محرّكات الذكاء الاصطناعي

من زر **«مفاتيح الذكاء الاصطناعي»** في الأعلى. تُحفظ المفاتيح في
`data/settings.json` على جهازك فقط، وتُرسل مباشرة إلى مزوّد الخدمة.

| المحرّك | يحتاج مفتاحًا | ملاحظات |
| --- | --- | --- |
| **محرّك محلي** (افتراضي) | لا | ماندالا/زهور/هندسي مرسومة رياضيًا، تعمل بدون إنترنت، 300 DPI |
| **OpenAI — gpt-image-1** | `sk-…` | أفضل التزام مع أوامر «line art». من platform.openai.com |
| **Stability AI** | `sk-…` | نموذج Stable Image Core، سريع واقتصادي |
| **Replicate — FLUX** | `r8_…` | جودة عالية، مناسب للتفاصيل الكثيرة |
| **Stable Diffusion محلي** | لا | يستهلك حاسوبك؛ شغّل Automatic1111 بـ `--api` على `http://127.0.0.1:7860` |

كل مولّدات الذكاء الاصطناعي تُرسل أمرًا (prompt) مصمّمًا خصيصًا لكتب التلوين:
خطوط سوداء سميكة، خلفية بيضاء نقية، بلا تظليل أو تدرجات أو ألوان أو نصوص.
ثم يمرّ الناتج على **خط المعالجة** التالي:

```
صورة من المزوّد → تنظيف وتباين → تتبّع الخطوط (Sobel) أو عتبة ثنائية
→ تنظيف النقاط المتناثرة → ضبط سماكة الخط → تكوين 300 DPI داخل صندوق المحتوى
```

## ما الذي يضمنه المحرّك من ناحية KDP

القيم مأخوذة من دليل النشر الورقي الرسمي لـ KDP:

- **عدد الصفحات:** الحد الأدنى 24، والملف يُقصّ إلى عدد زوجي (يُضاف صفحات بيضاء عند اللزوم).
- **الهامش الداخلي (Gutter):**

  | عدد الصفحات | الحد الأدنى |
  | --- | --- |
  | 24–150 | 0.375" |
  | 151–300 | 0.5" |
  | 301–500 | 0.625" |
  | 501–700 | 0.75" |
  | 701–828 | 0.875" |

- **الهوامش الخارجية:** 0.25" كحد أدنى بدون نزف، و0.375" مع النزف. التطبيق يستخدم
  0.5" تصميميًا + هامش أمان فوق الحد الأدنى للـ gutter.
- **النزف:** عند تفعيله يُصبح مقاس الصفحة `العرض + 0.125"` و`الارتفاع + 0.25"`.
- **الغلاف:** `العرض = 0.125 + عرض القطع + الكعب + عرض القطع + 0.125`،
  `الارتفاع = ارتفاع القطع + 0.25`.
- **الكعب:** `عدد الصفحات × سمك الورق` (أبيض/ألوان عادية 0.002252"، كريمي 0.0025"،
  ألوان فاخرة 0.002347").
- **نص الكعب:** يُمنع قبل 80 صفحة، ويُترك 0.0625" من كل حافة.
- **الباركود:** `2" × 1.2"` فارغ أسفل يمين الغلاف الخلفي، 0.25" من الكعب والحواف.
- **الصور:** 300 DPI، أسود/أبيض 1-bit، بلا تدرجات رمادية.
- **الخطوط:** مدمجة في PDF (DejaVu) — لا حاجة لتضمينها يدويًا.
- **الإفصاح عن الذكاء الاصطناعي:** يُذكّرك التطبيق بالرد بصدق على سؤال KDP،
  مع توضيح أن الإفصاح لا يمنع النشر.

## مشاكل شائعة وحلولها

| المشكلة | الحل |
| --- | --- |
| `run.bat` يغلق فورًا | ثبّت Python 3.10+ وفعّل «Add Python to PATH» ثم أعد التشغيل |
| «تعذّر الاتصال بالمزوّد» | تحقق من الإنترنت ومن صحة المفتاح، أو استخدم المحرّك المحلي |
| رسالة «API key غير صالح» | أعد إدخال المفتاح من زر المفاتيح؛ لا تضع مسافات زائدة |
| الصفحات تخرج رمادية | من محرّر الصفحة: ارفع «عتبة الأبيض/الأسود» إلى 170–190 ثم طبّق المعالجة |
| الخطوط رفيعة جدًا | ارفع «سماكة الخطوط» إلى 3 أو 4 |
| KDP يرفض الغلاف | تأكد أنك ترفع `cover.pdf` وليس `cover-proof.pdf`، وأن عدد الصفحات لم يتغيّر بعد التصدير |
| الكتاب رقيق جدًا | أضف رسمات (18–24) لتحصل على 40+ صفحة |
| المنفذ 8000 مشغول | `python midad.py --port 9000` |

**ملاحظة قانونية:** أنت مسؤول عن حقوق النصوص والصور التي ترفعها، وعن الإفصاح
الصحيح عن استخدام أدوات الذكاء الاصطناعي حسب سياسة KDP. راجع شروط KDP قبل النشر
التجاري. لا ترفع صورًا تحتوي علامات تجارية أو شخصيات محمية بحقوق نشر.

## English quick start

**Midad** is a local desktop studio for building AI-assisted coloring books that
pass Amazon KDP print review.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python midad.py
```

- **Zero-setup generation:** the built-in procedural engine draws mandalas,
  florals and geometric pages at 300 DPI — no API key, no internet.
- **Bring your own AI:** GPT-image-1, Stability AI, Replicate FLUX, or a local
  Stable Diffusion (A1111) endpoint. Keys stay in `data/settings.json`.
- **Print-ready output:** `interior.pdf` (trim size + 300 DPI, pure 1-bit),
  `cover.pdf` (full wrap with bleed, spine math and a clear 2"×1.2" barcode zone),
  `cover-proof.pdf` (with guides, never upload), plus KDP metadata and checklist.
- **Compliance engine:** 18+ automated checks — page count, gutter table, margins,
  DPI, B&W purity, cover math, spine text rules and AI disclosure reminders.

No cloud, no account, no telemetry. Everything runs on `127.0.0.1`.

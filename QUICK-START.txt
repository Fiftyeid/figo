==========================================================
  مِداد · Midad — استوديو كتب التلوين لـ Amazon KDP
  دليل التشغيل السريع
==========================================================

1) المتطلبات
   • Python 3.10 أو أحدث (ويندوز: فعّل "Add Python to PATH" أثناء التثبيت)
   • لا تحتاج مفاتيح ذكاء اصطناعي للبدء.

2) التشغيل
   ويندوز  : انقر مرتين على  run.bat
   ماك     : انقر مرتين على  run.command
   لينكس   : نفّذ  ./run.sh
   يدويًا   : python3 -m venv .venv
              source .venv/bin/activate        (ويندوز: .venv\Scripts\activate)
              pip install -r requirements.txt
              python midad.py

   أول تشغيل يستغرق 1–3 دقائق لتثبيت المكتبات، ثم تُفتح نافذة التطبيق
   تلقائيًا على:  http://127.0.0.1:8000

3) أول خطوة داخل التطبيق
   مشروع تجريبي جاهز سيظهر تلقائيًا. اضغط "تصدير ملفات KDP" لتحصل على:
      interior.pdf  ·  cover.pdf  ·  cover-proof.pdf  ·  metadata.txt
      kdp-checklist.md  ·  kdp-package.zip

4) الذكاء الاصطناعي (اختياري)
   زر "مفاتيح الذكاء الاصطناعي" ← OpenAI / Stability / Replicate
   أو استخدم Stable Diffusion المحلي على http://127.0.0.1:7860

   مجانًا: FreeLLMAPI — شغّل الخدمة مرة واحدة (تطبيق سطح المكتب أو
   npx freellmapi أو Docker) ثم افتح http://localhost:3001 وأضف مفاتيح
   المزوّدين المجانيين وانسخ "المفتاح الموحّد" (freellmapi-…).
   داخل مِداد: "مفاتيح الذكاء الاصطناعي" ← قسم FreeLLMAPI ← الصق المفتاح
   ← "اختبار الاتصال". يعمل للتخطيط النصي ولتوليد الصور معًا.

5) إيقاف التطبيق
   Ctrl + C في نافذة الأوامر. مشاريعك تُحفظ تلقائيًا في مجلد data/

مشاكل شائعة
   • "Python not found"          → ثبّت Python 3.10+ مع خيار Add to PATH
   • "port already in use"       → python midad.py --port 9000
   • نافذة run.bat تُغلق فورًا    → شغّل الطرفية داخل المجلد ونفّذ run.bat
   • صور رمادية في الطباعة        → من محرّر الصفحة ارفع "عتبة الأبيض/الأسود"

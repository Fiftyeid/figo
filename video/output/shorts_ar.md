## نصايح النشر
1. **انشر الفيديو الطويل الأول**، وبعدين شورت كل يوم أو يومين. ابدأ بالأقوى:
   القاهرة ← بني سويف ← البحر الأحمر ← الأقصر ← الدقهلية ← سوهاج ← الفيوم ← الجيزة.
2. **يوتيوب:** من YouTube Studio افتح الشورت ← «فيديو ذو صلة / Related video» واختار الفيديو الطويل.
   كده هيظهر لينك تحت الشورت يودّي على الفيديو الكامل بضغطة.
3. ثبّت كومنت فيه لينك الفيديو الكامل.
4. أول فريم في كل مقطع فيه العنوان والصورة، فينفع يبقى **الغلاف (Cover)** على طول.

## إعادة التوليد
المقاطع بتتولد أوتوماتيك من نفس مشروع الفيديو:
```bash
cd video/src
python3 shorts.py plan              # نقط القطع والمدد
python3 shorts.py preview luxor 3 10   # صور معاينة
python3 shorts.py all               # المقاطع -> video/build/shorts/
```
عشان تضيف محافظة جديدة: زوّد سطر في `SHORTS` جوه `src/shorts.py` (الجملة اللي القطع يبدأ منها + سؤال الافتتاحية)،
وولّد سؤال الافتتاحية بصوت الراوي في `assets/audio/shorts/hook_<id>.opus`.

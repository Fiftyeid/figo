# CoA required elements — IPEC-Americas guide for bulk pharmaceutical excipients

> **Source:** IPEC-Americas, *Certificate of Analysis Guide for Bulk Pharmaceutical Excipients*
> (public copy at <https://www.jpec.gr.jp/document/CertificateofAnalysisGuide2000.pdf>).
> Industry-standard guide used by excipient manufacturers worldwide to format their CoAs.

## Design and required elements of a Certificate of Analysis

The guide divides the CoA into four zones:

### 4.1 Header
- Titled **“Certificate of Analysis”**
- Company name, address, phone number, and identity of manufacturer and manufacturing site
- Name (compendial/trade) of excipient
- Grade of excipient
- Compendial designation (e.g., USP-NF, Ph. Eur.)

### 4.2 Body
- Lot/Batch number
- Date of manufacture
- Product code or number
- Expiration date (if required)
- Recommended re-evaluation date (if required)
- Stability statement (if required)
- Customer required information

### 4.3 Analysis
- Test name
- Test results
- Acceptance criteria (i.e., specifications)
- Reference to the test method
- Reference to skip-lot testing (if appropriate)
- Reference to average or in-process test results (if appropriate)
- Date retested (if appropriate)

### 4.4 Certification and compliance statements
- GMP compliance (IPEC Excipient GMPs)
- Statements of compliance with appropriate compendial requirements
- Regulatory statements (e.g., allergen, BSE/TSE, GMO, residual solvents) as applicable
- Signature of a responsible company official (QA/QC), name and date

### 4.5 Footer
- Document control number, revision number, page numbering (e.g., “Page 1 of 2”)

## Other key definitions (from the guide)

- **CoA:** a document communicating test results and compliance statements for a specific batch/lot.
- Dates on a CoA: date of manufacture, expiration/re-evaluation date, date retested — each has distinct meaning.
- When distributors re-issue CoAs, the original manufacturer’s CoA must be referenced/attached and the
  original manufacturer clearly identified.
- Testing frequency guidance (skip-lot testing) and CoA data transfer rules are also covered.

> Practical takeaway: whether you receive a CoA from an excipient, API or finished-product supplier,
> check that it carries all the elements above — a missing signature, batch number, or method reference
> is an audit finding.
